# Dataset access and licensing

`neurostreamlab dataset list`, `dataset info PhysionetMI`, and `dataset fetch PhysionetMI --subject 1` describe and retrieve the local protocol subset. Use BNCI2014_001 for multi-session data. NEUROSTREAMLAB_DATA overrides the default repository-local data directory. MNE_DATA is directed there and MNE_DONTWRITE_HOME prevents modifying the user's MNE home configuration. Epoch caches, downloaded EEG, replay arrays and model weights are ignored by Git.

PhysioNet EEG Motor Movement/Imagery v1.0.0: https://physionet.org/content/eegmmidb/1.0.0/, DOI 10.13026/C28G6P, Open Data Commons Attribution v1.0. The default hand-imagery subset downloads three EDF runs per subject using MNE's checksum-aware downloader. The entire dataset is not needed. Approximate default paper EDF download is 40 MB, actual bytes vary. Imagined hand runs 4/8/12 are selected, never executed runs 3/7/11. MOABB PhysionetMI(imagined=True, executed=False) is exposed for dataset metadata, while MNE retrieves only the three necessary hand runs to avoid unused feet/hands downloads.

BNCI2014_001 / BCI Competition IV 2a: https://bnci-horizon-2020.eu/database/data-sets. MOABB identifies CC BY-ND 4.0 and obtains the original MAT distribution from its NEMAR mirror when available. The executed run retrieved nm000139 v1.0.2, with upstream file SHA-256 provenance. About 250 MB is needed for the three selected subjects' two sessions. No raw or perturbed EEG is redistributed. Published artifacts contain aggregate metrics and task-label/probability arrays only. See THIRD_PARTY_NOTICES.md and local downloaded notices for source terms. Source hash records should be checked on fresh downloads if the upstream mirror changes.

Both datasets are adapted into EpochDataset: trials × ordered channels × time, labels, unique complete-trial IDs, session/run metadata and sample rate. The configuration chooses channels and event-relative epoch bounds. Multi-session train/test split is determined by complete session membership. Cached raw epoch keys describe adapter version, subject, dataset, channel list, epoch bounds and MNE version. Experiment caching separately hashes all Python source and full configuration. --force reruns a benchmark. Cached records never justify silently fitting on held-out data.
