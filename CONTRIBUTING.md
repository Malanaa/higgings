# Contributing

Run ./scripts/bootstrap.sh and make audit. Add regression tests for acquisition timing, model changes and scientific protocol changes. Keep public-data downloads out of CI. Report bugs with version, operating system, configuration, command and traceback. Never attach private EEG, credentials or identifying information. New sources implement the typed lifecycle and propagate metadata. New decoders implement fit, probability output and checksum-verified serialization. Numerical publication changes must regenerate all affected artifacts and pass provenance checks.
